# Gestor de tasques

API REST amb Node.js, Express i MongoDB per crear i gestionar tasques.

## Requisits

- Node.js i npm.
- MongoDB en execució local o una URI de connexió accessible.

## Instal·lació i arrencada

1. Instal·la les dependències:

   ```bash
   npm install
   ```

2. Crea el fitxer `.env` a partir de `.env.example` i ajusta la URI si cal.

3. Engega el servidor en mode desenvolupament:

   ```bash
   npm run dev
   ```

Per iniciar-lo sense el mode de desenvolupament, fes servir `npm start`.
